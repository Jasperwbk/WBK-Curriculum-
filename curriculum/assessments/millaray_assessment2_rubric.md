## Scoring notes
- Only MA-03 through MA-07 have single correct numeric answers; everything
  else is open-ended by design — score for reasoning/explanation quality,
  not a fixed string match.
- This is a **one-time placement test**, not a rotating pool — it's meant
  to be taken once per kid before daily generation starts, so no
  alternates/variants are needed here (unlike the retrofit check-question
  banks, which do rotate).
