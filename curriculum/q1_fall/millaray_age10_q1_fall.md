# Millaray (10 / Kira) — Quarter 1: Fall Curriculum

Generic age-10 starting point. Re-tune objectives once her real assessment is in —
nothing here is grade-benchmarked. Weekly budget: 28 hrs (17 core / 11 specialty),
season = fall, kid tag = Millaray/Kira throughout.

Weeks 5–9 add a second Social Studies strand: **American government & basic
economics**, layered in after the local-history sequence (Osage → Webster County →
Missouri) has run first, per the "start local, grow outward" history plan. It does
not replace local history — both strands run in parallel from Week 5 on.
