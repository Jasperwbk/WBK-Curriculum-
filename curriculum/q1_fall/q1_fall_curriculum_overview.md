# Wolf Blossom Homeschool — Quarter 1 (Fall) Curriculum: Overview & Compliance Framework

This file sets the shared structure behind the three kid-specific Q1 files. Read this
first, then open the file for the kid you're working with.

## How this plugs into the ecosystem
Every unit below follows **topic → 3–5 objectives → supporting content**, per
`learn_practice_test_alignment_standard.md`. Each unit is tagged with:
- **Subject code** (exact strings from the handoff notes)
- **Kid** it's built for
- **Season** (fall, all Q1)
- **Hours** (estimated instructional hours)
- **Field app** tag where it connects to an existing/planned WBK subject app

This means the objectives lists can be dropped straight into the Learn/Practice/Test
engine later with zero conversion work.

## Missouri compliance math (applies to Millaray, 10, and Makaio, 8 — both past
compulsory attendance age of 7; does NOT legally apply to Maizley, 2.5, but she's
tracked loosely anyway for portfolio consistency)

- Annual legal minimums: **1,000 total hours**, **≥600 core hours**
  (`reading_language_arts`, `math`, `science`, `social_studies_history`), **≥400 of
  those core hours at the home location**.
- Assuming a 36-week instructional year, Q1 (9 weeks) target pace:
  - **~250 total hours** (~27.8/week)
  - **~150 core hours** (~16.7/week)
  - **~100 home-core hours** (all of ours qualifies, since teaching happens on the
    property)
- Weekly hour budget used to build each week below (per kid, core + specialty):
  - Reading/Language Arts: 5 hrs
  - Math: 4 hrs
  - Science: 4 hrs
  - Social Studies/History: 4 hrs *(core subtotal: 17 hrs/week — exceeds the 16.7
    pace, banking a small surplus)*
  - Bushcraft/Outdoor Skills: 3 hrs
  - Homestead Skills: 3 hrs
  - Nature Identification: 3 hrs
  - Spiritual/Cultural: 2 hrs *(specialty subtotal: 11 hrs/week)*
  - **Total: 28 hrs/week x 9 weeks = 252 hrs for the quarter** — clears both the
    250-hour total pace and the 150-hour core pace, with margin.
- This is a flexible container, not a rigid bell schedule — per the family's low-
  rigidity requirement, hours can be logged as they actually happen (field-first),
  not forced into a fixed daily block. The ecosystem dashboard banks surplus/deficit
  against this pace automatically once hour-logging is live.

## Standing guardrails carried over from Odin Skald / the alignment standard
- Objectives-first, not topic-first, for everything below.
- Don't do the kid's practice work for them; don't build timed-pressure drills.
- Plant/fungi ID content always separates safe vs. dangerous look-alikes, caution-
  first.
- Assessments are still pending (printer access) — every unit below is built as a
  reasonable generic starting point for the stated age, explicitly flagged for
  re-tuning once real assessment data comes in. Nothing here is graded against a
  public-school grade level.
- Northwoods Kindred / Kindred Homestead remain the reference sources for seasonal
  and spiritual-cultural content.
