# Builder Note — Worksheet Style Preference

For whoever builds the daily worksheet/coloring-page generator, alongside
`09_image_bank_and_color_agenda.md` and `10_daily_color_sheet_model.md`.

**All three kids are artistic and respond best to interactive, playful
worksheets** — not plain drill sheets. Proven reference point: they engage
very well with the kind of premade activity workbooks sold at Walmart/Hobby
Lobby (dollar-bin/activity-book style) — mazes, matching, connect-the-dots,
word searches, fill-in-the-scene, puzzle-framed questions — more than a
standard column of problems.

**What this means for the generator:**
- Default to wrapping practice questions in an interactive format (maze
  where the path answer is correct, matching columns, word search of the
  week's vocabulary, fill-in-the-blank inside an illustrated scene) rather
  than a bare numbered list, wherever the objective allows it.
- The coloring-page system (Section 10) already fits this — extend the same
  instinct to the *worksheet* side, not just the color sheet.
- Straight drill format is fine as a fallback when a puzzle wrapper doesn't
  fit the objective (e.g. a spelling quiz), but shouldn't be the default.
- Applies across all three kids/bands — Maizley's version stays large-format
  and simple, Makaio's medium, Millaray's can carry more detail, but all
  three should feel like an activity, not a worksheet.
