## The recurring quarterly workflow (this is the part that didn't exist before)
When you come back with the real app-generated assessment printout:
1. **Read the printout per kid, per objective** — not per subject. It should
   show mastery status (per the v2 standard's tracking) for everything
   taught this quarter.
2. **Retune, don't rebuild.** Objectives that came back solid become
   warm-up/review material in the new quarter; objectives still shaky get
   re-taught before new ones stack on top, same remediation-loop logic as
   mid-quarter.
3. **New quarter's theme** comes from `seasonal_curriculum_framework.md`
   (Winter next). Same 9-week arc format, same 28 hrs/week hour math unless
   the printout shows pacing needs to change.
4. **Same file set per kid:** overview + weekly objectives/activities table,
   then the retrofit pass (check questions per objective), same as Q1.
5. **Printable touchpoints don't need rebuilding** — the subject-level
   pattern in `printable_touchpoints.md` holds regardless of season/quarter.
6. **Alignment standard doesn't change quarter to quarter** — it's the
   constant; only the objectives content feeding into it changes.

This means each future quarter should be faster than Q1 was — Q1 built the
scaffolding (standard, hour math, retrofit pattern, printable rules); Q2–Q4
just pour new season-specific content into that same shape.
