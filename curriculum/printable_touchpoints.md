# Printable Touchpoints — Q1 Reference

Flags where a printable naturally belongs, per subject. Applies across all
weeks/kids unless noted — the pattern repeats by subject type more than by
week theme. The **coloring page** side is already locked (Section 10's daily
rotation — one kid, one subject, one drawing per day). This covers the
**worksheet** side, styled per the interactive-first builder note.

| Subject | Worksheet fit | Style |
|---|---|---|
| math | **Yes, almost every day.** Counting, measuring, ratios, graphing all convert cleanly. | Wrap in maze/matching/fill-in-scene per the interactive note — e.g. "solve to find the path," not a bare problem column. |
| science | **Yes, most days.** Labeling diagrams, matching (part→job, cloud→weather), sequencing cards. | Diagram-label or matching-column format; sequencing cards work well for life-cycle objectives. |
| nature_identification | **Yes, almost every day.** ID matching, safe/unsafe sorting, track-to-animal matching. | Picture-matching or sorting-game format — this subject is naturally puzzle-shaped already. |
| social_studies_history | **Partial.** Map activities and timelines print well; discussion/interview objectives don't. | Map-marking or timeline-fill-in when the objective is factual; skip a worksheet for "ask a family member" or "discuss" objectives. |
| reading_language_arts | **Partial, skews narration.** Spelling/labeling objectives print well; "write a paragraph," "read aloud," "retell" don't need a worksheet — they need space and a listener. | When printable: word search (spelling weeks), sentence-order puzzle (sequencing weeks), fill-in-the-scene labeling. |
| bushcraft_outdoor_skills | **Rarely.** These are hands-on/demonstrated skills — a worksheet would substitute for doing it. | When printable at all: a simple safety-rule checklist or gear-packing checklist, not a quiz. |
| homestead_skills | **Rarely.** Same reasoning — real tasks, not desk work. | Checklist format only (inspection checklist, storage log) when a printable is useful. |
| spiritual_cultural | **Rarely.** Mostly discussion/participation. | Skip worksheets here — this is the one subject where the family's own guardrail (no invented ritual diagrams) also argues against manufacturing a printable for its own sake. |

## Age-band notes
- **Millaray:** worksheets can carry more steps/detail — a maze with 4–5
  problems along the path, a matching set of 6–8 pairs.
- **Makaio:** shorter versions of the same formats — 3–4 problems, 4–5
  matching pairs, bigger print.
- **Maizley:** no worksheets in this sense — her printable is the color
  sheet itself (Band A), or a simple large matching/pointing card at most,
  never a multi-step puzzle.

## How this fits with the color-sheet rotation
The color-sheet rotation already picks one **featured subject** per kid per
day for the drawing (Section 10's ring formula). The **worksheet** isn't
locked to that same subject — it should follow whatever subject the day's
actual lesson objective is in, per the table above. A kid can get a math
worksheet and a nature-ID color sheet on the same day; they don't need to
match.

## What's still open
This is a pattern reference, not a per-day printable — the engine still
generates the specific maze/matching-set/checklist from the day's actual
objective at generation time, same as it generates everything else from the
objectives list.
